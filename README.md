## 🧭 关于 AI‑VP

AI‑VP 是专注人工智能实战方向的开源组织。
我们整理、开发一系列面向入门学习者的开源教程与项目，覆盖大模型基础、Agent智能体、RAG检索增强、向量数据库、本地模型部署、Vibe Coding、具身智能等方向。

> 目标：降低AI技术学习门槛，提供可落地、可运行的完整实战案例，任何人都可以跟着动手实践。

## ✨ 组织特色

- 📚 **实战导向**：全部教程配套可运行代码，拒绝纯理论空谈
- 🧑‍🎓 **友好入门**：面向新手，循序渐进，从基础到大模型应用
- 📦 **轻量化**：优先支持本地部署，普通电脑也可以动手跑模型
- 🌐 **配套知识库**：统一文档站点，集中阅读所有项目文档
- 🤝 **社区共建**：欢迎大家提交Issue、PR，一起完善AI学习资料
