# AIVST 更新日志

所有重要的项目更改都记录在此文件中。

并遵循 [语义化版本](https://semver.org/lang/) 规范。

## [0.3.1] - 2026-09-20

### 🐛 修复

- 修复了首页 Hero 区域在暗色模式下图标显示异常的问题
- 解决了赞助页二维码在移动端拉伸变形的问题
- 修复了 Mermaid 图表在 SSR 构建时的渲染报错

### 🔒 安全

- 更新了第三方依赖包，修复已知安全漏洞
- 加强了文档站点的静态资源访问校验

## [0.3.0] - 2026-09-01

### ✨ 新增

- **自定义首页布局** - 新增组织主页 Hero 与 features 展示区
- **多语言配置** - 内置中文 / 英文双语文档结构
- **主题扩展配置** - 新增 `withAkTheme` 包装函数，自动处理构建与 SSR
- **响应式布局** - 全新适配桌面、平板、移动端

### 🎨 改进

- 重新设计了导航栏与侧边栏结构，操作更高效
- 优化了代码高亮主题，支持明暗切换
- 改进了本地搜索体验，支持离线检索

### ⚡ 性能

- 优化组件按需加载，首屏加载时间减少 35%
- 缓存机制优化，减少构建与页面请求负载
  感谢所有贡献者和用户的支持！❤️
