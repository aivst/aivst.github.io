# About AIVST

AIVST is a modern open‑source VitePress theme ecosystem built for private AI knowledge‑base documentation scenarios.

## Design Philosophy

We believe great AI documentation should balance ease‑of‑use, reading experience and feature richness. AIVST is committed to delivering:

- **Content‑Centered** — Make your AI‑related documents the top priority
- **Feature‑Rich** — Cover markdown writing, Mermaid diagrams, local search and custom page layouts
- **Easy Deployment** — Simple configuration, get your site running quickly
- **Highly Customizable** — Flexible settings to fit your knowledge‑base projects

## Key Features

### 🎨 Modern UI

- Clean modern interface
- Light / dark theme automatic switching
- Fully responsive layout for PC, tablet and mobile devices

### 🚀 Powerful Documentation Capabilities

- Custom home page layout for project introduction
- Multiple single‑page layouts for declaration and about pages
- Built‑in local full‑text search
- Mermaid diagram support
- Native bilingual i18n for Chinese‑English documents

### ⚡ Great Performance

- Built on Vite
- Fast hot‑reload for development
- Optimized static page rendering
- Good build output for static hosting

### 🔧 Easy to Extend & Deploy

- Simple npm package installation
- VitePress‑compatible configuration
- Component‑based theme architecture
- Plugin‑friendly design

## Development Team

AIVST is developed and maintained by the open‑source community team. We focus on AI knowledge‑base documentation solutions, aiming to build convenient theme tools for AI‑tech enthusiasts.

## Tech Stack

- **Vue 3** — Front‑end component library
- **VitePress** — Static documentation site generator
- **TypeScript** — Type‑safe development
- **Tailwind CSS** — Atomic CSS styling
