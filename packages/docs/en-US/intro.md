# Product Features

AIVST is an open‑source set of extended themes and components based on VitePress. It is specially built for building AI technical knowledge bases and LLM / RAG / Agent tutorial websites.

## ✨ Theme Capabilities

‑ Extend VitePress default layouts, provide custom home, sponsor page and changelog page layouts
‑ Full automatic light / dark theme switching support
‑ Rich built‑in icon components based on Tabler Icons

## 📖 Friendly for Document Writing

‑ Full native Markdown compatibility, no extra special syntax required
‑ Support Mermaid flowcharts and demo code preview blocks
‑ Built‑in bilingual document structure for maintaining English‑Chinese tutorials

## 📱 Responsive Layout

‑ Fully adaptive for desktop, tablet and mobile devices
‑ Auto‑collapsing navigation bar, optimized reading experience on small‑size screens

## ⚙️ Engineering & Automation

‑ Provide `withAkTheme` wrapper function to simplify theme import
‑ Compatible with GitHub‑Actions automatic deployment
‑ Support monorepo multi‑document repository scenarios

## 🧩 Customized for AI Knowledge Base

Suitable for writing:
‑ LLM practical tutorials
‑ RAG retrieval‑augmented practice documents
‑ Agent‑based intelligent agent development notes
‑ Ollama local deployment guides
