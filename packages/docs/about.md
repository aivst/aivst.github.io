# 关于 AIVST

AIVST 是面向AI知识库深度定制的 VitePress 开源主题生态。

## 设计理念

我们相信好的文档不仅需要内容丰富，更需要优秀的阅读体验。AIVST 致力于提供：

- **简洁优雅** - 干净的设计语言，突出内容本身
- **功能完整** - 提供AI技术文档所需的所有功能
- **易于使用** - 简单的配置，开箱即用
- **高度可定制** - 灵活的配置选项，满足不同知识库项目需求

## 主要特性

### 🎨 现代设计

- 基于现代设计语言
- 支持亮色/暗色主题自动切换
- 响应式设计，完美适配各种设备

### 🚀 强大功能

- 内置本地全文搜索功能
- Mermaid 流程图图表支持
- 多语言国际化双语支持
- 多种自定义页面布局

### ⚡ 性能优异

- 基于 Vite 构建
- 快速的热重载开发体验
- 优化的静态构建输出

### 🔧 易于扩展

- 丰富的主题配置选项
- 组件化架构
- 插件扩展支持

## 开发团队

AIVST 由开源社区团队开发和维护。我们是一个专注于AI开源项目的技术团队，致力于为开发者搭建优质的知识库文档工具。

## 技术栈

- **Vue 3** - 现代化的前端框架
- **VitePress** - 基于 Vite 的静态站点生成器
- **TypeScript** - 类型安全的开发体验
- **Tailwind CSS** - 原子化 CSS 框架

## 版本历史
