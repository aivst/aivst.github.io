# 产品特性

AIVST 是一套基于 VitePress 扩展的开源主题与组件集合，专门用来搭建 AI 技术知识库、LLM / RAG / Agent 教程站点。

## ✨ 主题能力

- 扩展 VitePress 默认布局，提供定制化首页、赞助页、更新日志页面布局
- 完整支持亮色 / 暗色两套主题自动切换
- 基于 Tabler Icons，内置丰富图标组件

## 📖 文档写作友好

- Markdown 全部原生兼容，无需额外特殊语法
- 支持 Mermaid 流程图、Demo 代码预览块
- 内置双语文档结构，方便维护中英文教程

## 📱 响应式布局

- 桌面、平板、手机移动端全部自适应
- 导航栏自动折叠，小屏幕阅读体验优化

## ⚙️ 工程与自动化

- 提供 `withAkTheme` 配置包装函数，简化主题引入
- 适配 GitHub‑Actions 自动部署
- 支持 monorepo 多文档仓库场景

## 🧩 面向AI知识库定制

适合编写：

- LLM 大模型实战教程
- RAG 检索增强实践文档
- Agent 智能体开发笔记
- Ollama本地部署指南
